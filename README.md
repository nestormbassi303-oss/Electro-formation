# ÉLECTRO FORMATION — projet Flutter de démarrage

Ce ZIP contient un squelette Flutter : accueil, liste de 10 chapitres, pages de leçon de démonstration, quiz simple et écran de progression.

## Important
Ce n'est **pas encore une application prête à vendre** : les textes complets et schémas du manuel PDF doivent être intégrés, les tests effectués, puis la version Android compilée et vérifiée.

## Compilation
Avec Flutter installé :
- `flutter pub get`
- `flutter run`
- `flutter build apk --release`
- `flutter build appbundle --release`

Le fichier AAB est destiné à la publication Google Play. Une inscription Play Console, la fiche de l'application, les déclarations de confidentialité et les tests exigés par Google restent nécessaires.

## Sécurité
Le contenu pédagogique ne remplace pas une formation pratique encadrée. Ne pas effectuer de travaux sur le réseau électrique domestique sans qualification.
